# My Concours — كونكوراتي

تطبيق لتتبع مباريات التوظيف العمومية (الكونكورات) والوثائق في المغرب: آخر الآجال، لائحات الوثائق المطلوبة، المستجدات (نتائج الكتابي، مواعيد الشفوي، النتائج النهائية)، والترشيح المباشر عبر البوابات الرسمية.

## الحالة (20 نونبر 2026)

- **نسخة التطبيق الكاملة** (تحفظ البيانات): تعمل داخل Muse — تتبع المباريات، خزنة الوثائق مع ماسح بالكاميرا، نماذج جاهزة (تصريح بالشرف، طلب خطي)، تحديث تلقائي للمستجدات من البوابات الرسمية.

1. شراء النطاق (myconcours.ma) باسم المالك.
2. استضافة مستقلة وربط النطاق.
3. نشر التطبيق على الموقع مع زر التثبيت.
4. حساب مطوّر Google Play (25 دولار مرة واحدة) + اختبار مغلق بـ12 مختبِراً لمدة 14 يوماً.
